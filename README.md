Random Quote Generator

About

Random Quote Generator is a website that displays random quotes based on selected categories. Users can explore quotes from various genres, including inspiration, love, success, and more, making it a great source for motivation and reflection.

Features

📌 Category Selection: Choose from multiple categories to get relevant quotes.

🔄 Randomized Quotes: Refresh to see a new quote each time.

🌟 Save & Share: Bookmark favorite quotes or share them on social media.

🎨 Minimal & Elegant UI: Simple, user-friendly design for seamless browsing.
